# Foxhole: игра на двух персах одновременно

Запускает два окна с разных Steam-аккаунтов Foxhole на одном экране. У каждого окна своя
клавиатура и мышь, и ввод в одном не мешает другому.

English version: [README.md](README.md).

## Статус

Сырой прототип. Проверено на одной машине: Fedora 44, Plasma 6.7 X11, Foxhole под
Proton, две USB-клавиатуры и две мыши. Тестов нет, на других дистрибутивах не пробовал
(там всё то же самое: X11 да uinput, отличие только в мелочах).
мимо.
Windows лень делать мне и не люблю. Там либо две виртуалки с пробросом USB, либо платный multiseat

## Это не чит

Никаких уязвимостей игры, инъекций кода, чтения и правки памяти процесса, вмешательства
в сеть и обхода античита. Всё обычными средствами:

- два клиента Steam со своими настройками (свой HOME, свой IPC-порт) — штатные флаги;
- вторая клавиатура и мышь — это XInput2 в X11, он ровно для этого и есть;
- автокликер — виртуальное устройство в `/dev/uinput`, обычное нажатие кнопки мыши.

## Требования

- Linux с Xorg (проверено: Fedora 44, KDE Plasma 6.7, X11, NVIDIA rxt5060ti).
- Две клавиатуры и две мыши. Боковая кнопка на второй мыши — опционально.
- Steam + Proton.
- `xinput`, Python 3.11+, `python3-evdev`, доступ на запись в `/dev/uinput`.

Права на ввод (без root в сессии):

```bash
sudo tee /etc/udev/rules.d/60-foxhole-input.rules >/dev/null <<'EOF'
KERNEL=="uinput", TAG+="uaccess"
SUBSYSTEM=="input", TAG+="uaccess"
EOF
sudo udevadm control --reload && sudo udevadm trigger
```

## Установка

```bash
git clone <repo> foxhole-dual && cd foxhole-dual
./install.sh --with-mpx      # лаунчеры, ярлыки, foxhole-input, MPX-демоны
./install.sh --shim          # опционально: шим для второго клиента
```

## Как пользоваться

```bash
foxhole-input doctor     # проверить uinput / evdev / XInput2
foxhole-both             # поднять оба клиента и обе игры
```

Окна — рядом, в windowed/borderless может быть даже фулскрин получиться. Первая пара работает в первом окне, вторая во втором.

Второе место поднимает `seat2-start` при логине. Устройства для него лежат в
`~/.config/foxhole-dual/devices.conf`:

```bash
foxhole-input devices        # список клавиатур/мышей и их места
foxhole-input setup          # выбрать пару для второго места
foxhole-input setup --auto   # взять то, что сейчас на втором месте
```

## Автокликер

```bash
foxhole-input run      # демон (можно в автозапуск)
foxhole-input status
foxhole-input stop
```

Конфиг: `~/.config/foxhole-dual/input.toml`.

```toml
[[bind]]
trigger = "mouse:side"   # боковая кнопка любой мыши, клик по курсору этой мыши
action  = "click:0.05"
seat    = "auto"

[[bind]]
trigger = "key:j"        # J на этой клавиатуре, место берётся у клавиатуры
action  = "click:0.05"
seat    = "auto"

[[bind]]
trigger = "key:4"        # зажим ПКМ для твинка
action  = "hold:right"
seat    = 2              # только со второй клавиатуры
```

`seat = auto` — место того устройства, с которого нажали. `seat = 1/2` — жёстко, и без
`device =` привязка срабатывает только с устройств этого места. `click:N` — переключатель,
клик раз в N секунд; `hold:left/right` — зажатие до повторного нажатия. Триггеры:
`key:x`, `ctrl+alt+a`, `mouse:side`, `mouse:extra`, `mouse:back`.

Не держите одновременно старые `autoclick`/`autoclick-hotkey`/`seat2-rmb-hold` и
`foxhole-input` — будет по два срабатывания.

## Примеры применения

В основном это удобно для управления танком — если у вас нет друзей или вы хотите быть
намного эффективней — садитесь одним персонажем на мехвода, вторым на наводчика. Таким
образом вы сможете иметь хороший обзор и великолепно выцеливать при помощи обрыва
максимальной дальности пехоту в окопах.

**Починка.** Починка всем экипажам доступна через автокликер:

1. вылезти;
2. нажать единицу, чтобы взять молоток;
3. навестись на танк;
4. нажать автокликер;
5. повторить с другим аккаунтом — таким образом вы будете чинить во всю силу.

**Постройка.** Похожим образом возможно заниматься постройкой: сначала размечаете
чертежи, а далее переставляете каждый аккаунт с автокликером — вдвоём строить быстрее.

**Споттер.** Так же есть вариант использовать твинк как наводчика, если вы стреляете из
гамбота/ручного миномёта/чего либо ещё — я добавил автоматический зажим правой кнопки
мыши для того, чтобы споттер оставлял камеру на одном месте и вам было удобно целиться.

Применений масса — главное иметь хорошо развитые полушария мозга.

## Как это работает, коротко

- **Аккаунты:** второму клиенту `-master_ipc_name_override 127.0.0.1:57344` и та же
  переменная `steam_master_ipc_name_override` в окружении, её наследует игра. Без этого
  обе игры цепляются к первому клиенту и показывают один аккаунт.
- **Ввод:** мастер-пара XInput2 `second pointer`/`second keyboard`. `seat2-cp` ставит
  окну ClientPointer по `HOME` процесса игры, `seat2-focuspin` держит XI-фокус второй
  клавиатуры на окне Wine (ищет по `WM_STATE`, а не по фрейму KWin).
- **Клики:** создаётся `uinput`-устройство и привязывается к мастеру того места, с
  которого пришло нажатие, поэтому кликает по его курсору.
